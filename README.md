# Customer-Churn-Prediction

# Project Overview
  This project focuses on predicting customer churn using Supervised Machine Learning techniques. Customer churn refers to customers who       stop using a company’s service. Identifying such customers helps businesses take preventive actions and improve retention.

# The project includes:
    -> Custom dataset creation
    -> Exploratory Data Analysis (EDA)
    -> Data preprocessing
    -> Model training using multiple algorithms
    -> Performance evaluation and comparison

# Machine Learning Models Used
  # 1. Decision Tree Classifier
      -> Captures complex relationships
      -> Easy to interpret
      -> May overfit on training data
  
  # 2. K-Nearest Neighbors (KNN)
      -> Works based on similarity between data points
      -> Sensitive to feature scaling
      -> Simple but effective for small datasets
